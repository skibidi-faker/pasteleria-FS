# Pastelería Mil Sabores

Sitio web para la pastelería **Mil Sabores**. El proyecto presenta información de la pastelería, productos destacados, catálogo de la tienda, inicio de sesión y registro de usuarios.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página de inicio con información, productos destacados, testimonios y contacto.
- Catálogo de tortas y postres en la tienda.
- Acceso y registro de usuarios.
- Beneficios promocionales durante el registro:
  - Código `FELICES50`: 10% de descuento de por vida.
  - Correo institucional `@duocuc.cl`: torta gratis de cumpleaños.
- Desplazamiento suave hacia la sección "Sobre nosotros".

## Estructura del proyecto

```text
pasteleria-FS/
├── index.html          # Página principal
├── tienda.html         # Catálogo de productos
├── login.html          # Inicio de sesión
├── registro.html       # Registro de usuarios
├── css/
│   └── style.css       # Estilos del sitio
├── js/
│   ├── main.js         # Interacciones de la página principal
│   └── form.js         # Validación y beneficios del registro
└── img/                # Imágenes del sitio
```

## Uso

1. Clona o descarga el repositorio.
2. Abre `index.html` en un navegador web.

No se requiere instalación de dependencias ni servidor para ejecutar el proyecto.
